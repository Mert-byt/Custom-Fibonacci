# Custom-Fibonacci
Custom Fibonacci Open-source Pine Script v6 indicator for ICT / Smart Money Concepts. Automatically plots specialized Fibonacci levels (-0.29, -0.255, -0.21, 0, 1, 1.47, 1.51, 1.55, 2.56, 2.60, 2.64) from Pivot High to subsequent Pivot Low. Clean lines, fully customizable. Designed for liquidity sweeps, accumulation zones and extension targets.
